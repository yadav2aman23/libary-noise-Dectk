# Firmware

Place your Arduino sketch in this folder.

Suggested filename:

`ESP32_Library_Noise_Monitor_FIXED.ino`

Before publishing, review the sketch for:
- Wi-Fi SSID and password
- Firebase URLs, tokens, API keys, or private credentials
- GPIO assignments used for I2S
- Required library names and versions

Do not upload secrets to a public GitHub repository. The sketch itself was not included in this starter archive; add your local `.ino` file here.
